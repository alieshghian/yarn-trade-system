# قرارداد تحویل گروه‌های آزمایشگاه

مرجع مشترک: `cascadingTreeContract.ts` در کنار قراردادهای موجود آزمایشگاه. کامپوننت ثبت‌شدهٔ `base-form.cascading-tree-panels` برای گروه کالا، اشخاص و درخت‌های بعدی استفاده می‌شود؛ کامپوننت موازی ساخته نشود.

خروجی «JSON همین فرم» ساختار و Designer فعلی را بدون تعمیر، تغییر ابعاد، ارتقای قالب مادر یا بازنویسی تنظیمات صادر می‌کند. اکنون manifest رفتارهای ارث‌برده و اختصاصی، قرارداد درخت و snapshot تاریخچهٔ Undo/Redo همان سند نیز همراه آن است. شناسه و قالب نسخهٔ ۱ خروجی برای مصرف‌کننده‌های فعلی حفظ شده است.

این خروجی جایگزین پشتیبان کامل مرورگر نیست: recovery journal تاریخی، ترجیحات شخصی حساب، کتابخانهٔ اجرایی کامپوننت و داده‌های زندهٔ آزمایش را شامل نمی‌شود. `scope` این مرز را صریح معرفی می‌کند. قرارداد، مشخصات مورد انتظار است؛ به‌تنهایی اثبات اجرای صحیح همهٔ رفتارها نیست.

تعداد زیرگروه‌ها تنظیم ساختاری مدیر است و کاهش آن نباید گره‌ها را حذف کند. سطح‌های غیرفعال پنهان می‌شوند. تنظیمات ظاهری کاربر فقط در محدودهٔ مجوزهای فرم مجاز است؛ API عملیاتی باید مجوز مدیر و محدودیت سطح‌ها را سمت سرور نیز کنترل کند.

در آزمایشگاه، گره‌های افزوده‌شده در session کامپوننت نگهداری می‌شوند. داده‌های موجود در schema fixture هستند؛ به‌عنوان رکورد واقعی وارد دیتابیس نشوند. اتصال عملیاتی بعدی باید ذخیره‌سازی، تخصیص اتمی کد و کنترل تکرار سمت سرور را از نقاط اتصال موجود انجام دهد. کد عمومی گزارش از ریشه می‌آید؛ شناسهٔ سطر، شناسهٔ گره است.

پیش از تغییر یا مهاجرت نسخهٔ شخصی کاربر، خروجی تازهٔ همان مرورگر دریافت و مستقل بررسی شود. پشتیبان تاریخی به‌عنوان آخرین طراحی معرفی نشود. هیچ ابعاد، رنگ، شناسهٔ جدول یا تنظیم اختصاصی برای هماهنگ‌سازی خودکار با قالب مادر بازنویسی نشود.
