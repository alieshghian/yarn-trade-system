# ترجمه عنوان کلیدها در آزمایشگاه

واژه‌نامه مشترک عنوان‌های شناخته‌شده را فوری ترجمه می‌کند. عنوان ناشناخته پس از مکث ۵۰۰ میلی‌ثانیه به API خود برنامه ارسال می‌شود؛ پاسخ قدیمی یا لغوشده اعمال نمی‌شود. درخواست اینترنتی فقط از سرور به ارائه‌دهندهٔ تنظیم‌شده می‌رود. هیچ کلیدی داخل فرانت‌اند یا JSON طراحی ذخیره نمی‌شود.

در محیط Development، سرویس MyMemory بدون کلید فعال است. فقط عنوان کوتاه کلید به مسیر HTTPS رسمی `/get` ارسال می‌شود؛ هیچ ردیف جدول، اطلاعات حساب یا سند کامل ارسال نمی‌شود و مسیر مشارکت `/set` هرگز فراخوانی نمی‌شود. سقف عمومی سرویس ۵۰۰۰ نویسه در روز است؛ اتمام سهمیه خطا محسوب می‌شود و عنوان قبلی حفظ می‌شود. برای فعال‌سازی همین سرویس در محیط دیگر:

```
Translation__Enabled=true
Translation__Provider=MyMemory
```

برای استفاده از Microsoft به جای سرویس عمومی، مدیر سرویس باید این تنظیمات را با متغیر محیطی سرور یا secret manager تنظیم و API را دوباره اجرا کند:

```
Translation__Enabled=true
Translation__Provider=Microsoft
Translation__Azure__Key=<secret>
Translation__Azure__Region=<region-if-required-by-resource>
```

ایجاد حساب، دریافت کلید، سهمیه و هزینه سرویس باید توسط مالک انجام شود. کلید را در Git، فایل تحویل فرم یا چت قرار ندهید. ساخت خودکار حساب یا خرید سرویس انجام نشده است. مرجع API: https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/v3/translate

مرجع MyMemory: https://mymemory.translated.net/doc/spec.php و https://mymemory.translated.net/doc/usagelimits.php . این سرویس عمومی برای عناوین رابط کاربری است؛ برای متن محرمانه باید ارائه‌دهندهٔ خصوصی تنظیم شود. محدودیت ورودی MyMemory، ۵۰۰ بایت UTF-8 است. پاسخ هر دو زبان پیش از اعمال یا cache اعتبارسنجی می‌شود.

مسیر POST `/api/laboratory/label-translations` فقط برای Administrator دارای مجوز `formLaboratory.view` است. ورودی فقط متن ساده با سقف ۱۶۰ نویسه و زبان fa/en/zh است. آدرس سرویس از ورودی کاربر گرفته نمی‌شود. محدودیت درخواست ۲۰ بار در دقیقه برای هر حساب، timeout هشت ثانیه و cache حافظه‌ای محدود اعمال می‌شود. cache سرور حداکثر ۲۵۶ عبارت تا یک ساعت و cache مرورگر حداکثر ۱۲۸ عبارت در session است.

هر عنوانی که کاربر دستی ویرایش کند با `manualLabels` محافظت می‌شود. نتیجه خودکار با `autoLabels` منشأ دارد؛ این metadata در Designer، تاریخچه و خروجی می‌ماند. overrideهای قدیمی ناشناخته محافظه‌کارانه دستی محسوب می‌شوند. دکمه «ترجمه خودکار دوباره» برای زبان مقصد، حفاظت آن مقصد را صریحاً برمی‌دارد و ترجمه را از زبان فعال درخواست می‌کند. فونت، رنگ، اندازه و هندسه تغییر نمی‌کنند.

بدون اینترنت، بدون پیکربندی یا هنگام خطای سرویس، متن‌های قبلی حذف نمی‌شوند؛ پیام مشخص می‌کند که نیاز به بررسی دارند. ترجمه آنلاین تضمین معنایی نیست و اصطلاحات تخصصی باید بازبینی شوند. این پیاده‌سازی مسیر مشترک عنوان کلیدهای فرم‌ها را پوشش می‌دهد؛ اتصال سایر انواع متن به همین سرویس باید از adapter مربوط انجام شود.
