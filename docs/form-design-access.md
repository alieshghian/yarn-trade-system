# دسترسی مستقیم و آزمایش فرم‌های طراحی‌شده

- بخش مشترک `FormLaboratoryPage` بالای خود فرم، «ورود اطلاعات آزمایشی»، نشانی مستقیم و امکان کپی آن را نمایش می‌دهد. فرم‌های مستقل فعلی و جدید همین بخش را دریافت می‌کنند؛ هندسهٔ ذخیره‌شده به قالب مادر منتقل نمی‌شود.
- نشانی پایدار از شناسهٔ فرم در پارامتر `formDesign` استفاده می‌کند: `http://127.1.0.1:5173/?formDesign=<form-id>`؛ تغییر عنوان، شناسه را تغییر نمی‌دهد.
- بازکردن نشانی نیازمند حساب مجاز و اطلاعات محلی همان مرورگر است؛ لینک به‌تنهایی فرم را به مرورگر یا رایانهٔ دیگری منتقل نمی‌کند. مسیر ورود/فعال‌سازی حساب حفظ می‌شود.
- «ورود اطلاعات آزمایشی» همان موتور آزمایشی موجود را فعال می‌کند؛ داده‌ها موقت‌اند و به API عملیاتی ارسال نمی‌شوند. خروج از آزمایش با «پایان آزمایش عملکرد» انجام می‌شود.
- «خروجی JSON همین فرم» فقط سند فعلی و تنظیمات Designer آن را دانلود می‌کند. خروجی با `source.kind=current-designer` مشخص می‌شود؛ ممکن است با نسخهٔ قبلاً ثبت‌شده در صف اتصال متفاوت باشد. این عمل ذخیره، حذف، انتشار یا جایگزینی فرم نیست.
- صفحهٔ کمکی `http://127.1.0.1:5173/form-lab-export.html` فقط نسخهٔ ثبت‌شدهٔ منو را می‌خواند و فرم برند با سه فیلد و سه ستون را نمایش می‌دهد. بازکردن فایل HTML با `file:///` صحیح نیست. این صفحهٔ کمکی به سرور توسعه نیاز دارد و بخشی از خروجی production نیست؛ خروجی‌گیری داخل خود فرم در Build وجود دارد.

## قرارداد رفتاری نهایی فرم‌های آزمایشگاه ـ نسخهٔ ۲

- مرجع واحد رفتار فرم‌های عملیاتی، `frontend/src/components/base-form/laboratoryOperationalBehavior.json` است. خروجی JSON آزمایشگاه باید همین قرارداد را در کنار `form` و `designerDraft` داشته باشد؛ اطلاعات شناسایی خروجی و منبع آن هم در JSON باقی می‌ماند.
- فرم‌های جدید باید از اجزای مشترک `FormSchemaPresentation`، `BaseFormGridBoundary`، `ExcelGridColumnHeader`، `OperationalFormFrame`، `DesignerFontPanel`، `ExcelColorPicker` و `exportGridWorkbook` استفاده کنند. رفتار مشترک را در فرم جداگانه کپی یا بازنویسی نکنید؛ هر فرم فقط طرح، شناسهٔ پایدار، داده و اتصال API خودش را تعیین می‌کند.
- جدول اندازهٔ پایدار دارد و فقط در صورت بیشتر شدن محتوا اسکرول می‌شود. در فارسی، شروع دید از سمت راست است و تغییر اندازه با جهت منطقی همان ستون کار می‌کند. عرض ستون‌ها، ارتفاع سرستون، ارتفاع نوار جدول و نسبت فضای فرم/جدول مطابق مجوز کاربر ذخیره می‌شوند.
- خروجی XLSX به‌شکل آیکن با راهنمای شناور/فوکوس در کنار کنترل‌های جدول قرار می‌گیرد؛ داده‌های فیلتر و مرتب‌شده و ستون‌های قابل‌نمایش را با عنوان، سرستون قالب‌بندی‌شده، ردیف‌های راه‌راه، کادرها، سرستون ثابت و فیلتر اکسل صادر می‌کند.
- منوی فیلتر هر ستون معکوس‌کردن انتخاب مقادیر را کنار «انتخاب همه» دارد؛ آیکن و راهنما حالت آن را نشان می‌دهند و کلیک دوباره انتخاب را برمی‌گرداند. کنترل جداگانهٔ وارونه‌سازی نتیجهٔ جست‌وجو نیز نتیجه‌های نامنطبق را نشان می‌دهد و با کلیک دوباره به نتیجه‌های منطبق برمی‌گردد.
- در Designer، اجزای نوار ابزار جداگانه انتخاب می‌شوند؛ با Ctrl یا Command می‌توان چند جزء را انتخاب و با هم جابه‌جا کرد. در فرم عملیاتی، برچسب‌ها و کنترل‌های رابط انتخاب متنی نمی‌شوند؛ Ctrl+A فقط محتوای ویرایش‌پذیر یا داده‌های قابل‌مشاهدهٔ جدول را انتخاب می‌کند و انتخاب چند سلول جدول با Ctrl/Command و کپی پشتیبانی می‌شود.
- مجوزهای رنگ و قلم، منوی راست‌کلیک و پنل‌های مشترک آزمایشگاه را برای هدر فرم و عنوان ثابت آن، پنل و فیلدها، نوار جدول، جست‌وجو در حالت عادی و فوکوس، گزینه‌های جست‌وجو، سرستون‌ها، ردیف‌ها و سلول‌ها به‌کار می‌برند. تغییر رنگ هنگام انتخاب زنده پیش‌نمایش می‌شود و لغو، رنگ قبلی را برمی‌گرداند. امکان تغییر اندازه و ذخیره/خروج بدون ذخیره نیز از همان قرارداد پیروی می‌کند.
- تنظیم‌های شخصی کاربر با کلید ترکیبی شناسهٔ کاربر و شناسهٔ پایدار فرم در مرورگر ذخیره می‌شوند؛ این مقادیر از `designerDraft` جدا هستند. JSON طراحی، ساختار فرم و وضعیت Designer را نگه می‌دارد و قرارداد رفتار را برای پیاده‌سازی مشترک فرم‌های بعدی حمل می‌کند.
- فایل ثابت `frontend/src/forms/brand-design.json` باید همین نسخهٔ قرارداد را داشته باشد و همچنان طرح برند با شناسهٔ `form.redesign.805deb77-bec5-41fa-af97-77b7007ca3a4` و دقیقاً سه فیلد و سه ستون را حفظ کند. کنترل زمان اجرا در `brandDesign.ts` ناهماهنگی قرارداد را رد می‌کند.
- هر تغییر آینده در رفتار مشترک باید ابتدا در همین قرارداد و اجزای مشترک ثبت و پیاده‌سازی شود، شمارهٔ نسخهٔ قرارداد به‌روزرسانی شود و نسخهٔ تعبیه‌شده در JSON فرم‌های ثبت‌شده همگام بماند. فرم جدید نباید برای این رفتارها نسخهٔ اختصاصی بسازد.
